# Small Guy Big Guy
Small Guy Big Guy is a platformer made in Godot.

# Development
To develop, `git clone` this repo and use the Godot 4 editor.

## Installation
Grab a copy for your OS and architecture from releases and run it. To run the web build, unzip the file and host it using a web server.

## Tech Stack
This game was made in Godot 4. To avoid spending time tiling the floor, this awesome [autotiler](https://route1rodent.itch.io/autotiler) was used.
